## مميزات المنصة التفاعلية (GitHub Pages Ready)

- **محاكاة هولوغرام ثلاثية الأبعاد تفاعلية حية (3D Interactive Hologram Canvas)** لجميع أسئلة الهيكل (`Q.1 → Q.20`) مع إمكانية **تحريك الشحنات الكهربائية بالماوس أو اللمس وتغيير نوع الشحنة (`+ موجبة / − سالبة / 0 متعادلة`)** وتدوير المجسم `360°`.
- **معادلات رياضية حقيقية (بسط ومقام وجذور وأسس)** مفصولة عن النص العربي.
- **فهرس الأسئلة التفاعلي حسب أسئلة الهيكل (`Q.1 → Q.20`)** + **مكتبة الهولوغرام 3D** + **شهادة إنجاز الطالب**.
